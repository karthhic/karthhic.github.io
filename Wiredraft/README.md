# WireDraft website

A self-contained landing page with Documentation and Contact views. Everything it needs is in this folder:

```
site\
  index.html     the page (Product, #docs and #contact views)
  img\           logo and screenshots used by the page
```

Published as a claude.ai artifact: https://claude.ai/artifact/UKFthbSNX58hZTFxoRpe5g

To update the screenshots, replace the files in `img\` with the same names and republish.
The page loads its fonts from Google Fonts; the contact form stores messages with the artifact,
so it works only when published there.
